# AI Finder 배포본

macOS 파일 관리자 [AI Finder](https://finder.speciai.kr)의 배포 파일을 두는 곳입니다.

## 내려받기

[릴리스](https://github.com/kimlawtech/ai-finder-releases/releases/latest)에서 받으세요.

- Apple Silicon 맥: `AIFinder-x.y.z-arm64.dmg`
- Intel 맥: `AIFinder-x.y.z-x64.dmg`

내려받은 dmg를 열고 앱을 Applications 폴더로 옮기면 됩니다.
Apple 공증을 마쳐 별도 경고 없이 실행됩니다.

macOS 12 이상이 필요합니다. macOS 11을 쓰신다면
[0.4.5](https://github.com/kimlawtech/ai-finder-releases/releases/tag/v0.4.5)를 받으세요.
