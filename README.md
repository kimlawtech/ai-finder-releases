# Zipper 배포본

macOS 파일 검색·정리 도구 [Zipper](https://github.com/kimlawtech/zipper)의 배포 파일을 두는 곳입니다.
소스코드는 별도 저장소에 있습니다.

## 내려받기

[릴리스](https://github.com/kimlawtech/zipper-releases/releases/latest)에서 받으세요.

- Apple Silicon 맥: `Zipper-x.y.z-arm64.dmg`
- Intel 맥: `Zipper-x.y.z.dmg`

내려받은 dmg를 열고 앱을 Applications 폴더로 옮기면 됩니다.
Apple 공증을 마쳐 별도 경고 없이 실행됩니다.

첫 실행 때 데스크탑·다운로드·서류 폴더 접근 권한을 물어봅니다. 허용해야 파일을 찾습니다.

## 업데이트

설치한 앱이 이곳을 보고 새 버전을 확인합니다. 자동으로 설치하지는 않고,
새 버전이 있으면 설정 탭에서 알려 드립니다.
